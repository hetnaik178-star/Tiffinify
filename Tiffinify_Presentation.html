💡 The Problem
Working Indians Deserve Better Food
Millions of professionals, students & families struggle with inconsistent, unhealthy, or overpriced food options daily. Tiffinify bridges this gap.
😩
The Daily Struggle
Ordering from Zomato/Swiggy daily is expensive (₹300–500/day), inconsistent in quality, and lacks nutritional focus for health-conscious users.
🏠
The Gap
Local tiffin services exist but are offline & unorganized — no digital tracking, no menu preview, no dietary customization, no digital payments.
✅
Our Solution
Tiffinify digitizes the tiffin experience — daily menus, subscriptions, customization, real-time tracking, and seamless payment in one beautiful app.

🔐 Auth & Onboarding
Smart User Onboarding
A frictionless 3-step onboarding flow with intelligent new-user detection and profile setup.
  • 🌅

    Animated Splash Screen

    Custom Tiffinify logo animation with delivery illustration on launch.

  • 📖

    3-Page Onboarding

    Beautiful illustrated cards explaining the value proposition — shown only once on first install.

  • 📱

    OTP Mobile Login

    Mobile number + 4-digit OTP with mock API. State persisted in SharedPreferences.

  • ✏️

    Smart Profile Setup

    Auto-detects new users — routes to profile name setup before Home screen.

🔄
Session Persistence
Login state persisted via SharedPreferences — users stay logged in across app restarts.
🛡️
Mock OTP Verification
Accepts any 4-digit OTP for demo. Production-ready to swap with a real SMS gateway (Twilio/2Factor).
⚡
Smart Routing
New user → Profile Setup → Home. Returning user → Home. Onboarded → Skip onboarding.

🍽️ Menu & Ordering
Dynamic Daily Menu System
Fresh Breakfast, Lunch & Dinner with dietary filters and complete cart-to-payment flow.
🥦
Diet Type Filtering
Home screen chips: Veg, Non-Veg, Jain, All. Each item shows a colored diet badge instantly on filter.
🕐
3 Meal Time Sections
Menu divided into Breakfast, Lunch, and Dinner. Each item has name, price, dietary tag, description, and add-to-cart button.
🛒
Smart Cart System
Full cart — add/remove items, live quantity, subtotal, ₹30 delivery charge, 5% GST, and grand total calculated in real time.
🎨
Meal Customization Templates
Save preferences (extra roti, no onion, less spice) as templates. Set any template as default for instant one-tap ordering.

💳 Payments
Mock Razorpay Gateway
A fully simulated, authentic Razorpay payment gateway — production-ready architecture, ready to go live.
  • 💳

    Razorpay Online Payment

    UPI (GPay, PhonePe, Paytm, BHIM), Debit/Credit Cards, Netbanking options in the gateway.

  • 💵

    Cash on Delivery

    COD — user pays cash to the delivery partner on arrival.

  • 👛

    Tiffinify Wallet

    In-app wallet with ₹120 demo balance. Deducted on payment with live balance check.

  • 🔑

    Mock Payment ID

    Generates unique Payment ID (e.g. pay_rzp_mock_98234) simulating real Razorpay response.
